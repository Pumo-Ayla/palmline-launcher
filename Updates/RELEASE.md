**1.0.4.1 · 普通更新**

磁力下载和组件自检使用随包提供的 .NET 9 x64。启动时检查一次更新，每次点击「检查更新」再查一次。下载与重试复用本次检查结果，继续校验更新包大小和 SHA-256。

全新安装请解压 `SRLauncher-1.0.4.1.zip` 并运行 `SRLauncher.exe`。

从 1.0.4 或更早版本升级，请将 `SRLauncher-1.0.4.1-offline.zip` 解压到单独的临时文件夹。关闭旧启动器和游戏，运行包内的 `Upgrade-Launcher.exe`，输入旧启动器所在目录。完成后从原目录启动。

GitHub 的 Source code (zip) 用于再开发。
