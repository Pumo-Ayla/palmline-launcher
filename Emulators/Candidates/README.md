# Candidate compatibility layers

This directory is for Xbox Series compatibility layers under evaluation for Series Relay Launcher. It currently has no entries. The launcher uses the [catalog of bundled layers](../catalog.json) for its released builds.

To propose a layer, open a pull request that adds a folder named after the upstream project. In its README, link to the upstream repository, identify the exact tag or commit and license, and describe the build or download used for testing. Record the Windows version, GPU, launch command, observed result and known limitations. If redistribution is permitted, include the license and a SHA-256 checksum alongside any binary you submit.

## 预选兼容层

这里用于存放 SRLauncher 正在评估的 Xbox Series 兼容层，目前暂无候选项目。已随启动器发布的兼容层可在[正式清单](../catalog.json)中查看。

提交候选项目时，请通过拉取请求新建一个以上游项目命名的子目录。在说明中列出上游地址、实际测试的标签或提交号、许可证和构建来源，再写明测试使用的 Windows 版本、显卡、启动命令、运行结果和已知问题。如附带可再分发的二进制文件，请一并提供许可证和 SHA-256 校验值。
